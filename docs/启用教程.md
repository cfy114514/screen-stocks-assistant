# 中文启用教程

## 1. 下载和解压

在 [Releases](https://github.com/cfy114514/screen-stocks-assistant/releases/latest) 下载 `ScreenStocksAssistant-v0.1.0-windows-x64.zip`，完整解压到普通目录，例如 `D:\ScreenStocksAssistant`。

双击运行的是 `ScreenStocksAssistant.exe`，不是 GitHub 自动生成的 `Source code.zip`。便携版内含所需运行环境，无需另装 Python。构建为 Windows x64；当前没有代码签名。

## 2. 退出游戏，备份设置

先正常退出《桌面股神》。游戏运行时可能覆盖设置文件。

在文件资源管理器地址栏输入：

```text
%USERPROFILE%\AppData\LocalLow\Conradical Games\Screen Stocks
```

找到 `thesmallshort_online_settings.sav`，复制一份，例如命名为：

```text
thesmallshort_online_settings.sav.backup
```

如果文件不存在，先通过 Steam 启动一次游戏并退出。`AppData` 默认可能隐藏，直接在地址栏输入路径即可进入。

## 3. 打开 Mod 支持

用记事本打开原始 `thesmallshort_online_settings.sav`，搜索 `modSupport`。

它在 JSON 结构的 `SettingsData.value` 中。只把：

```json
"modSupport": false
```

改成：

```json
"modSupport": true
```

结构示意如下，**不要把整个存档替换成这个示意片段**：

```json
{
  "SettingsData": {
    "__type": "SettingsData,Assembly-CSharp",
    "value": {
      "modSupport": true
    }
  }
}
```

保留其他设置、逗号和括号；使用 UTF-8 保存，文件名仍是 `.sav`，不要变成 `.sav.txt`。

## 4. 启动游戏，检查导出

重新启动游戏并进入在线市场。正常情况下，原目录下会出现：

```text
mods\
  mod-settings.json
  export\
    market.json
    history.json
  commands\
    $PLAIN\
      buymax.json
      buypercent.json
      ...
  skins\
```

`market.json` 是当前行情、持仓、冷却、排期和命令回报；`history.json` 是近期价格样本。只启动菜单界面、未进入在线市场时，行情可能尚未就绪。

若游戏生成了 `mods\mod-settings.json`，确认其中启用了导出和命令：

```json
{
  "export": true,
  "commands": true,
  "skins": true
}
```

`skins` 与交易无关，保持自己的设置即可。不要手工把 `commands` 中的 `execute` 改成 `true` 来测试，它会向游戏发出真实游戏交易指令。

## 5. 打开盯盘网页

双击 `ScreenStocksAssistant.exe`，默认浏览器会打开类似 `http://127.0.0.1:随机端口/` 的页面。

- 确认顶部显示行情连接正常、数据时间持续更新。
- 模拟账户独立记账，不修改游戏持仓。
- 普通均价策略需要至少 3 分钟、60 个有效价格样本。游戏重启后可能需要重新等待预热。
- 点击排期的计划时间，可以查看北京时间、发布时间和近期价格。
- 自动交易初始关闭；本工具不会修改游戏的 `modSupport` 设置，也不会替你创建游戏内槽位。

## 6. 调整助手配置

第一次启动后，助手自己的配置文件在：

```text
%LOCALAPPDATA%\ScreenStocksAssistant\config.json
```

这与游戏的 `.sav` 设置文件是两个不同文件。先在网页点击“退出助手”，再编辑配置，修改后重新双击 EXE。

示例：

```json
{
  "game_dir": "C:\\Users\\你的用户名\\AppData\\LocalLow\\Conradical Games\\Screen Stocks",
  "game_managed_stocks": ["$BANK", "$BUBL"],
  "manage_existing_shorts": false
}
```

- `game_dir`：游戏存档目录；通常无需改，程序会自动使用当前 Windows 用户路径。JSON 中反斜杠需要写两次。
- `game_managed_stocks`：外置程序排除的股票内部代码。没有游戏内自动槽位时可设为 `[]`，但请先核对游戏中的已有自动规则。
- `manage_existing_shorts`：首次建立自动交易状态时，是否接管已经存在的空头，默认 `false`。已建立的保护列表会保存在交易状态中，不会因改配置直接重新计算；不要在有未确认指令时删除或重置交易状态。

界面名称与内部代码不一定相同，例如 `$BASE` 的内部代码是 `$PLAIN`，`$BEAT` 是 `$VOID`，`$TEAM` 是 `$STEAM`。

## 7. 游戏内槽位的可选设置

如果要沿用默认分工，可以在游戏界面中自行设置以下五个槽位。它们是固定价格示例，需要随游戏版本和行情自行评估：

| 股票 | 条件 | 动作 |
|---|---|---|
| BUBL | ≤8.5 | 买入25% |
| BUBL | ≤8 | 买入25% |
| BUBL | ≥11 | 平多100% |
| BANK | ≤9.5 | 买入25% |
| BANK | ≥10.5 | 平多100% |

**平多是卖出现有多头，不能误选为做空。** 默认外置程序排除这两只股票，避免一边买、一边卖。游戏内槽位有独立冷却，条件持续满足时可能重复触发，并可能在外置助手关闭后继续工作。

## 8. 启动、停止、退出

在网页点击“启动自动交易”才会向游戏本地 Mod 接口提交指令。会使用真实的游戏现金并影响已有多头；规则见 [交易规则](交易规则.md)。当前仅允许游戏版本 `1.0.13` 启用外置自动交易。

“停止自动交易”会停止新指令并核对已经发出的指令；“退出助手”会停止交易进程并退出网页服务。关闭网页或浏览器不等于停止助手。再次双击 EXE 可找回页面，不必记住随机端口。

不要同时运行旧脚本版、多个不同助手或其他交易机器人。不同工具的锁文件可能不共享，仍可能重复下单。

## 常见情况

| 现象 | 检查方式 |
|---|---|
| 找不到行情 | 游戏是否进入在线市场；`modSupport`、`export` 是否开启；`game_dir` 是否正确 |
| 显示运行中但没有动作 | 检查3分钟预热、游戏冷却、90秒平仓保护、排期前90分钟冻结、可买股数及是否满足信号 |
| 交易停止 | 查看页面停止原因和 `%LOCALAPPDATA%\ScreenStocksAssistant\自动交易运行日志.txt`，不要反复重启以强行重复发单 |
| 指令超时后停止 | 程序保留待确认记录；重新启动会先核对原指令和持仓，不能凭“超时”断言交易失败 |
| 公告时间看起来已经过了 | 区分“发布时间”和“计划执行时间”；页面详情固定显示北京时间 |
| 没看到某股下一次周期 | 导出只能提供游戏已经发布的排期，不保证能提前知道所有周期或日常涨跌 |
| 浏览器崩溃 | 双击 EXE 重新打开页面；后台可能仍在运行 |

## 个人数据在哪里

所有助手状态保存在 `%LOCALAPPDATA%\ScreenStocksAssistant\`：配置、自动交易记录、模拟记录、资金采样、日志与锁文件。发布包和源码不包含任何玩家的历史记录。删除程序目录不会自动删除这些状态；卸载前先正常退出，保留记录便于核对尚未确认的指令。
